# 0.3 සිට මාරු වීම

Sinling 0.4 නැවත සැලසුම් කළ අනුවාදයකි; 0.3 API ඉවත් කර ඇත. ඔබට තවම මාරු විය නොහැකි නම්, පැරණි
අනුවාදය සවි කරන්න:

```
pip install "sinling<0.4"
```

## දේවල් ගිය තැන {#where-things-went}

| 0.3 | 0.4 |
| --- | --- |
| `SinhalaTokenizer().tokenize(sentence)` | `sinling.tokenize(text)` |
| `SinhalaTokenizer().split_sentences(text)` | `sinling.sentences(text)` |
| `SinhalaTweetTokenizer().tokenize(tweet)` | `sinling.tokenize(text)`: URL, mentions, hashtags සහ emoji තනි ටෝකන වේ |
| `SinhalaStemmer().stem(word)` | `sinling.stem(text)`, හෝ තනි වචනයක් සඳහා පහත පරිදි `(stem, suffix)` |
| `preprocess(text)` | `sinling.normalize(text)` |
| `POSTagger().predict(sentences)` | 0.4 හි තවම නැත; `sinling<0.4` සවි කරන්න |
| `word_joiner.join(a, b)` | 0.4 හි නැත; `sinling<0.4` සවි කරන්න |
| `word_splitter.split(word)` | 0.4 හි නැත; `sinling<0.4` සවි කරන්න |

0.3 හි `SinhalaStemmer().stem(word)` `(base, suffix)` ලබා දුන් අතර පෙරනිමියෙන් ප්‍රකෘති ශබ්දකෝෂය
භාවිත කළේය. 0.4 හි පෙරනිමි backend එක `suffix` වේ; තනි වචනයක් සඳහා 0.3 හැසිරීම ලබා ගැනීමට:

```python
from sinling.registry import get_backend

stemmer = get_backend("stem", "dictionary")
stemmer.split("අංකයක්")  # ('අංක', 'යක්')
```

## හැසිරීමේ වෙනස්කම් {#behaviour-changes}

**ටෝකනීකරණය**

- ටෝකනීකරණයට පෙර පෙළ සාමාන්‍යකරණය කෙරේ. 0.3 හැසිරීම සඳහා `normalize=False` දෙන්න.
- ටෝකනකාරකය තවදුරටත් අකුරු මකා දමන්නේ නැත. 0.3 `é` සහ `ñ` වැනි උච්චාරණ සලකුණු සහිත ලතින් අකුරු
  ඇතුළුව අකුරු 80 ක් පමණ ඉවත් කළේය.
- කෙටි යෙදුම් තම තිත රඳවා ගන්නේ වචනයක ආරම්භයේදී පමණි. 0.3 හි `ගව.` වලින් අවසන් වන වාක්‍යයක තිත
  වචනයට ඇලී, වාක්‍යය කිසි විටෙකත් අවසන් නොවීය.
- `3.14`, `1,000`, `10:30` වැනි සංඛ්‍යා තනි ටෝකන වේ. 0.3 `0.` සිට `9.` දක්වා කෙටි යෙදුම් ලෙස
  සැලකූ නිසා, වාක්‍යයක් අවසානයේ `10.` එය අවසන් නොකළේය.
- `ඒ` වැනි කෙටි යෙදුම්ද වන වචන, පසුපසින් එන තිත රඳවා ගන්නේ `ඒ.බී.` වැනි දාමයක් තුළ පමණි.
