# ඇගයීම

Sinling කෙතරම් නිවැරදිද? සෑම අංගයක්ම, මිනිසුන් අතින් පරීක්ෂා කළ, ප්‍රසිද්ධියේ ලබා ගත හැකි සිංහල
පෙළ මත පරීක්ෂා කෙරේ. ඔබටද එම පරීක්ෂණ, ඔබේම දත්ත මතද, ධාවනය කළ හැකිය.

## පරීක්ෂණ ක්‍රියා කරන ආකාරය {#how-the-tests-work}

- පරීක්ෂණ ගොනු සෑම විරාම ලකුණකටම පෙර හිස්තැනක් තබයි (`ගියා .`). මිනිසුන් ලියන ආකාරයේ පෙළ
  දැකීමට, Sinling මුලින්ම එම හිස්තැන් ඉවත් කරයි. ගොනුවේ ඇති ආකාරයටම පරීක්ෂා කිරීමට
  `text="given"` දෙන්න.
- වචනයක් නිවැරදි ලෙස ගණන් ගන්නේ Sinling එය හරියටම එකම තැනින් බෙදුවොත් පමණි.
- වාක්‍යයක් නිවැරදි ලෙස ගණන් ගන්නේ එය එකම තැනින් අවසන් වුවහොත්ය.
- `normalize()` ඇතුළුව, සාමාන්‍ය භාවිතයේදී මෙන්ම එකම පියවර හරහා පෙළ යයි.

## පරීක්ෂණ ධාවනය කිරීම {#running-the-tests}

විධාන පේළියෙන්:

```
python -m sinling evaluate
python -m sinling evaluate --task tokenize --dataset my-test-set.conllu
```

Python වලින්:

```python
report = sinling.evaluate("sentences", "ud-sinhala-appuwa")
report.precision, report.recall, report.f1
```

ඔබේම දත්ත මත පරීක්ෂා කිරීමට, Universal Dependencies භාවිත කරන CoNLL-U ආකෘතියේ ගොනුවක මාර්ගය
දෙන්න; සෑම වාක්‍යයකටම `# text =` පේළියක් අවශ්‍යයි. කාර්යයට දෙන විකල්පම මෙහිද දිය හැකිය,
උදාහරණයක් ලෙස `evaluate("tokenize", "ud-sinhala-stb", extra_abbreviations=["ඩො."])`.
