# වචන සහ වාක්‍ය

## වචනවලට බෙදීම {#splitting-into-words}

`tokenize()` පෙළ වචන, සංඛ්‍යා, විරාම ලකුණු සහ වෙනත් කොටස්වලට බෙදයි; මේ කොටස් ටෝකන (tokens)
ලෙස හැඳින්වේ. පෙළ මුලින්ම `normalize()` මගින් පිරිසිදු කෙරේ. ටෝකන සෑම විටම පෙළේ නිවැරදි කොටස්
වන නිසා, එක් එක් ටෝකනය මුල් පෙළේ සොයා ගත හැකිය.

```python
>>> import sinling
>>> sinling.tokenize("ඔහු (COVID-19) ගැන 3.14% ක් කීවේය!")
['ඔහු', '(', 'COVID', '-', '19', ')', 'ගැන', '3.14', '%', 'ක්', 'කීවේය', '!']

```

නල මාර්ගයක් තුළ, සෑම ටෝකනයක්ම එය කුමන වර්ගයේ ටෝකනයක්දැයි `token.attrs["kind"]` හි කියයි:

| වර්ගය | උදාහරණ |
| --- | --- |
| `word` | `ගෙදර`, `COVID`, `10ට` (ප්‍රත්‍යයක් සහිත සංඛ්‍යාවක් වචනයක් ලෙස ගණන් ගැනේ) |
| `number` | `2026`, `3.14`, `1,000`, `10:30` |
| `abbreviation` | `පෙ.ව.`, `රු.`, `ඒ.බී.` |
| `punct` | `.`, `,`, `...` (නැවත නැවත යෙදෙන ලකුණු එකට රැඳේ) |
| `symbol` | `%`, `£`, `©` |
| `url`, `email`, `mention`, `hashtag` | `https://example.lk`, `name@example.lk`, `@user`, `#ශ්‍රීලංකාව` |
| `emoji` | සම පැහැය සහ ඒකාබද්ධ emoji ඇතුළුව, emoji එකක් |
| `other` | ඉතිරි ඕනෑම දෙයක් |

```python
>>> doc = sinling.pipeline(["tokenize"])("රු.500 #ශ්\N{ZERO WIDTH JOINER}රීලංකා")
>>> [(t.text, t.attrs["kind"]) for t in doc.tokens][:3]
[('රු.', 'abbreviation'), ('500', 'number'), ('#ශ්\u200dරීලංකා', 'hashtag')]

```

### කෙටි යෙදුම් {#abbreviations}

`රු.` සහ `පෙ.ව.` වැනි පොදු කෙටි යෙදුම් තම තිත රඳවා ගනී. කෙටි යෙදුමක් ලෙස ගණන් ගන්නේ වචනයක
ආරම්භයේදී පමණි; ඒ නිසා `ගව.` වලින් අවසන් වන වාක්‍යයක් එතැනින්ම අවසන් වේ.

සමහර කෙටි යෙදුම් `ඒ` වැනි එදිනෙදා වචනද වේ. ඒවා තිත රඳවා ගන්නේ `ඒ.බී.` හෝ `පා.ම.` හි මෙන්
වෙනත් කෙටි යෙදුමක් කෙළින්ම පසුපසින් එන විට පමණි; නැතහොත් `ඒ.` යනු `ඒ` වචනය සහ තිතකි.

ඔබේම කෙටි යෙදුම් එක් කිරීමට `extra_abbreviations=` දෙන්න:

```python
>>> sinling.tokenize("ඩො. සිල්වා", extra_abbreviations=["ඩො."])
['ඩො.', 'සිල්වා']

```

සම්පූර්ණ ලැයිස්තු `sinling.tokenization.ABBREVIATIONS` සහ `CHAIN_ABBREVIATIONS` වේ;
`abbreviations=` සහ `chain_abbreviations=` මගින් ඒවා ප්‍රතිස්ථාපනය කළ හැකිය.

## වාක්‍යවලට බෙදීම {#splitting-into-sentences}

`sentences()` පෙළ වාක්‍යවලට බෙදයි. වාක්‍යයක් අවසන් වන්නේ:

- `.` `?` `!` `…` හෝ කුණ්ඩලිය `෴` ට පසුව, ඊට කෙළින්ම පසුව ඇති වසන උද්ධෘත ලකුණක් හෝ වරහනක්
  සමඟ;
- හිස් පේළියකදී;
- නව ලැයිස්තු අයිතමයකට පෙර: අංකයක් සහ තිතකින් (`1.`) හෝ බුලට් එකකින් ආරම්භ වන පේළියක්.

```python
>>> sinling.sentences('ඔහු කීවේ "මම එනවා." ඊට පසු ගියේය.')
['ඔහු කීවේ "මම එනවා."', 'ඊට පසු ගියේය.']

>>> sinling.sentences("1. පළමු කරුණ\n2. දෙවන කරුණ")
['1. පළමු කරුණ', '2. දෙවන කරුණ']

```

කෙටි යෙදුමක් වාක්‍යයක් අවසන් නොකරයි; කෝලනයක් හෝ අර්ධ විරාමයක්ද එසේමය.

නල මාර්ගයක් තුළ, වාක්‍ය `doc.sents` හි ඇත:

```python
>>> doc = sinling.pipeline()("මම යනවා. ඔයා එනවා.")
>>> [doc.span_text(s) for s in doc.sents]
['මම යනවා.', 'ඔයා එනවා.']

```
