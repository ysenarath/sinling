# ටෝකන සහ වාක්‍ය

## ටෝකනීකරණය {#tokenization}

`tokenize()` පෙළ වචන, සංඛ්‍යා, විරාම ලකුණු සහ වෙනත් ටෝකනවලට (tokens) බෙදයි. පෙළ මුලින්ම
සාමාන්‍යකරණය කෙරේ. ටෝකනීකරණය කිසි විටෙකත් පෙළ වෙනස් නොකරයි; ඒ නිසා සෑම ටෝකනයක්ම මුල් පෙළට
ආපසු සිතියම්ගත කළ හැකිය.

```python
>>> import sinling
>>> sinling.tokenize("ඔහු (COVID-19) ගැන 3.14% ක් කීවේය!")
['ඔහු', '(', 'COVID', '-', '19', ')', 'ගැන', '3.14', '%', 'ක්', 'කීවේය', '!']

```

නල මාර්ගයක් තුළ, සෑම ටෝකනයක්ම තම වර්ගය `token.attrs["kind"]` හි සටහන් කරයි:

| වර්ගය | උදාහරණ |
| --- | --- |
| `word` | `ගෙදර`, `COVID`, `10ට` (ප්‍රත්‍යයක් සහිත සංඛ්‍යාවක් එක් වචනයකි) |
| `number` | `2026`, `3.14`, `1,000`, `10:30` |
| `abbreviation` | `පෙ.ව.`, `රු.`, `ඒ.බී.` |
| `punct` | `.`, `,`, `...` (එකම ලකුණේ පෙළක් එක් ටෝකනයකි) |
| `symbol` | `%`, `£`, `©` |
| `url`, `email`, `mention`, `hashtag` | `https://example.lk`, `name@example.lk`, `@user`, `#ශ්‍රීලංකාව` |
| `emoji` | සම පැහැය හෝ ZWJ අනුපිළිවෙළ සහිත emoji එකක් |
| `other` | ඉතිරි සියල්ල, උදාහරණයක් ලෙස තනිව ඇති සංයුක්ත ලකුණක් |

```python
>>> doc = sinling.pipeline(["tokenize"])("රු.500 #ශ්\N{ZERO WIDTH JOINER}රීලංකා")
>>> [(t.text, t.attrs["kind"]) for t in doc.tokens][:3]
[('රු.', 'abbreviation'), ('500', 'number'), ('#ශ්\u200dරීලංකා', 'hashtag')]

```

### කෙටි යෙදුම් {#abbreviations}

හඳුනන කෙටි යෙදුම් (abbreviations) තම තිත රඳවා ගනී. ඒවා හඳුනාගන්නේ වචනයක ආරම්භයේ පමණි; ඒ නිසා
`ගව.` වලින් අවසන් වන වාක්‍යයක් එතැනින්ම අවසන් වේ. ලැයිස්තු දෙකක් ඇත:

- `ABBREVIATIONS` තනිවම පවතී: `බී.`, `එම්.` වැනි මුලකුරු, සහ `රු.`, `ක්‍රි.`.
- `CHAIN_ABBREVIATIONS` සාමාන්‍ය වචනද වේ (`ඒ`, `පා`) හෝ `පෙ.ව.`, `අ.පො.ස.`, `පා.ම.` වැනි
  දාමවල පමණක් හමු වේ. ඒවා තම තිත රඳවා ගන්නේ වෙනත් කෙටි යෙදුමක් කෙළින්ම පසුපසින් ඇති විට
  පමණි.

ඔබේම කෙටි යෙදුම් `extra_abbreviations=` මගින් එක් කරන්න; නැතහොත් ලැයිස්තුවක් සම්පූර්ණයෙන්
`abbreviations=` හෝ `chain_abbreviations=` මගින් ප්‍රතිස්ථාපනය කරන්න:

```python
>>> sinling.tokenize("ඩො. සිල්වා", extra_abbreviations=["ඩො."])
['ඩො.', 'සිල්වා']

```

## වාක්‍ය {#sentences}

`sentences()` පෙළ වාක්‍යවලට බෙදයි; අවශ්‍ය නම් මුලින්ම ටෝකනීකරණය කරයි. වාක්‍යයක් අවසන් වන්නේ:

- `.` `?` `!` `…` හෝ කුණ්ඩලිය `෴` ට පසුව, ඊට කෙළින්ම ඇලී ඇති වසන උද්ධෘත හෝ වරහන් සමඟ;
- හිස් පේළියකදී;
- ලැයිස්තු අයිතමයකට පෙර: අංකයක් හා තිතකින් (`1.`) හෝ බුලට් එකකින් ආරම්භ වන පේළියක්.

```python
>>> sinling.sentences('ඔහු කීවේ "මම එනවා." ඊට පසු ගියේය.')
['ඔහු කීවේ "මම එනවා."', 'ඊට පසු ගියේය.']

>>> sinling.sentences("1. පළමු කරුණ\n2. දෙවන කරුණ")
['1. පළමු කරුණ', '2. දෙවන කරුණ']

```

කෙටි යෙදුම් වාක්‍යයක් අවසන් නොකරයි. පේළියක ආරම්භයේ තිතක් සහිත අංකයක් ලැයිස්තු සලකුණකි.
කෝලනයක් හෝ අර්ධ විරාමයක් කිසි විටෙකත් වාක්‍යයක් අවසන් නොකරයි.

නල මාර්ගයක් තුළ වාක්‍ය `doc.sents` හි ටෝකන දර්ශක පරාස (spans) ලෙස ගබඩා වේ:

```python
>>> doc = sinling.pipeline()("මම යනවා. ඔයා එනවා.")
>>> [doc.span_text(s) for s in doc.sents]
['මම යනවා.', 'ඔයා එනවා.']

```
