# ලේඛන සහ නල මාර්ග

`tokenize()` වැනි ශ්‍රිත ඔබට සරල ලැයිස්තුවක් දෙයි. වචන ඒවායේ ස්ථාන සමඟ, වාක්‍ය සහ ප්‍රකෘති
වැනි තවත් දේ අවශ්‍ය වූ විට නල මාර්ගයක් (pipeline) භාවිත කරන්න. එය ඔබේ පෙළ මත පියවර කිහිපයක්
ධාවනය කර, සියලු ප්‍රතිඵල සහිත `Doc` එකක් ලබා දෙයි.

```python
>>> import sinling
>>> nlp = sinling.pipeline(["normalize", "tokenize", "sentences"])
>>> doc = nlp("\N{ZERO WIDTH SPACE}මම යනවා. ඔයා එනවා.")

```

`sinling.pipeline()` තනිවම ධාවනය කරන්නේද මෙම පියවර තුනමය. නල මාර්ගයක් එක් වරක් සාදා, ඔබේ සියලු
පෙළ සඳහා එය නැවත භාවිත කරන්න; සෑම විටම අලුතින් සෑදීමට වඩා එය වේගවත්ය.

## Doc එකක ඇති දේ {#whats-in-a-doc}

| ගුණාංගය | අඩංගු දේ |
| --- | --- |
| `doc.raw` | ඔබ දුන් පෙළ, හරියටම දුන් ආකාරයට. |
| `doc.text` | පිරිසිදු කිරීමෙන් හෝ ෆොන්ට හැරවීමෙන් පසු පෙළ. |
| `doc.tokens` | වචන සහ අනෙක් ටෝකන. සෑම එකකටම එහි `text`, `doc.text` තුළ එහි `start` සහ `end` ස්ථාන, සහ වැඩිදුර විස්තර සහිත `attrs` ඇත. |
| `doc.sents` | වාක්‍ය. |
| `doc.spans` | Sinling ට ඒවා සොයා ගත හැකි වූ පසු, පුද්ගල සහ ස්ථාන නාම වැනි වෙනත් වචන කාණ්ඩ. |
| `doc.meta` | සමස්ත පෙළ පිළිබඳ සටහන්, උදාහරණයක් ලෙස පැරණි ෆොන්ට හැරවීමක් නොදැන සිටි අකුරු. |

```python
>>> doc.text
'මම යනවා. ඔයා එනවා.'
>>> doc.tokens[1]
Token(text='යනවා', start=3, end=7, attrs={'kind': 'word'})
>>> doc.span_text(doc.sents[1])
'ඔයා එනවා.'

```

## ප්‍රතිඵල ඔබේ මුල් පෙළේ සොයා ගැනීම {#finding-results-in-your-original-text}

පෙළ පිරිසිදු කිරීමෙන් සහ හැරවීමෙන් එය වෙනස් විය හැකි නමුත්, සෑම දෙයක්ම පැමිණියේ කොතැනිනිදැයි
`Doc` එක මතක තබා ගනී. `doc.to_raw()` වචනයක, වාක්‍යයක හෝ `doc.text` හි ඕනෑම කොටසක ස්ථානය ඔබේ
මුල් පෙළේ ලබා දෙයි; උදාහරණයක් ලෙස එය ඉස්මතු කිරීමට:

```python
>>> start, end = doc.to_raw(doc.tokens[1])
>>> (start, end), doc.raw[start:end]
((4, 8), 'යනවා')

```

මෙහි මුල් පෙළ නොපෙනෙන අකුරකින් ආරම්භ වන නිසා, සෑම ස්ථානයක්ම එකකින් ඉදිරියට යයි.

## පියවර තෝරා ගැනීම {#choosing-the-steps}

සෑම පියවරක්ම එහි කාර්යයේ නාමයෙන් දක්වන්න. පියවරක් කරන ආකාරය තෝරා ගැනීමට හෝ එයට විකල්ප
දීමට, යුගලයක් හෝ තුනක් භාවිත කරන්න:

```python
nlp = sinling.pipeline([
    ("legacy_font", "fm"),
    ("normalize", "rules", {"preset": "search"}),
    "tokenize",
    {"task": "stem", "backend": "dictionary"},
])
```

පිරිසිදු කිරීම සහ ෆොන්ට හැරවීම වැනි පෙළ වෙනස් කරන පියවර මුලින්ම තිබිය යුතුය; නැතහොත් දෝෂයක්
ලැබේ. `sentences` සහ `stem` වැනි වචන අවශ්‍ය පියවරවලට පෙර `tokenize` නොමැති නම්ද දෝෂයක් ලැබේ.

## Doc එකක් සුරැකීම {#saving-a-doc}

`doc.to_dict()` `Doc` එකක් JSON ලෙස සුරැකිය හැකි සාමාන්‍ය dict සහ ලැයිස්තු බවට හරවයි.
`Doc.from_dict()` ස්ථාන ද ඇතුළුව ඒවා නැවත `Doc` එකක් බවට හරවයි:

```python
>>> import json
>>> copy = sinling.Doc.from_dict(json.loads(json.dumps(doc.to_dict())))
>>> copy.to_raw(copy.tokens[1])
(4, 8)

```
