# සාමාන්‍යකරණය

එකම සිංහල වචනය විවිධ ආකාරවලින් ගබඩා විය හැකිය: දෘශ්‍ය අනුපිළිවෙළට (visual order) ටයිප් කර,
PDF එකකින් පිටපත් කර, නොපෙනෙන අක්ෂර සමඟ ඇලවූ ලෙස, හෝ සම්බන්ධකයක් (joiner) වැරදි තැනක තබා.
ඒවා එක හා සමාන ලෙස පෙනුණත් පරිගණකයට සමාන නොවේ. ඒ නිසා සෙවීම, ගණන් කිරීම සහ ඊළඟ සෑම
පියවරක්ම වැරදේ. `normalize()` පෙළ එක් සම්මත යුනිකේත ආකාරයකට හරවයි.

```python
>>> import sinling
>>> sinling.normalize("\N{ZERO WIDTH SPACE}\N{SINHALA VOWEL SIGN KOMBUVA}කා\N{NO-BREAK SPACE}අා")
'කො ආ'

```

`tokenize()`, `sentences()`, `stem()` සහ `from_legacy_font()` මුලින්ම පෙළ සාමාන්‍යකරණය කරයි;
එය නොකළ යුතු නම් `normalize=False` ලෙස දෙන්න.

## නීති {#rules}

නීති මෙම අනුපිළිවෙළට ක්‍රියාත්මක වේ:

| # | විකල්පය | කරන දේ | උදාහරණය |
| --- | --- | --- | --- |
| 1 | `invisible` | ශුන්‍ය-පළල හිස්තැන්, BOM, මෘදු යා-ඉරි, වචන සම්බන්ධක සහ දිශා සලකුණු ඉවත් කරයි. | `ක` U+200B `ර` → `කර` |
| 2 | `zwj` | සෑම ශුන්‍ය-පළල සම්බන්ධකයක්ම (ZWJ) SLS 1134 අපේක්ෂා කරන තැනට ගෙන යයි; අනවශ්‍ය ZWJ සහ ZWNJ ඉවත් කරයි. සිංහල අකුරු අසල ඇති සම්බන්ධක පමණක් වෙනස් වන නිසා emoji අනුපිළිවෙළවල් ආරක්ෂිත වේ. | `ක` U+200D U+0DCA `ය` → `ක` U+0DCA U+200D `ය` |
| 3 | `doubled_signs` | කොම්බු දෙකක් කොම්බු දෙක ලකුණ (`ෛ`) බවට හරවයි; `ෲ` සහ `ෳ` සඳහාද එසේමය. | U+0DD9 U+0DD9 → U+0DDB |
| 4 | `reorder` | ව්‍යඤ්ජනයට පෙර ටයිප් කළ ස්වර ලකුණක් (දෘශ්‍ය අනුපිළිවෙළ) සම්පූර්ණ ව්‍යඤ්ජන සමූහයට පසුවට ගෙන යයි. | U+0DD9 `ග` → `ගෙ` |
| 5 | `vowel_letters` | ස්වතන්ත්‍ර ස්වරයක් හා ලකුණක් එක් ස්වර අකුරක් බවට හරවයි; යුනිකේත සම්මතයේ "භාවිත නොකළ යුතු" අනුපිළිවෙළ ලැයිස්තුව (DoNotEmit.txt) අනුගමනය කරයි. | `අ` + `ා` → `ආ` |
| 6 | `nfc` | යුනිකේත NFC; තාර්කික අනුපිළිවෙළට ටයිප් කළ කොටස් දෙකේ ස්වර ලකුණු එක් කරයි. | U+0DD9 U+0DCF → `ො` |
| 7 | `whitespace` | හිස්තැන්, ටැබ් සහ වෙනත් යුනිකේත හිස්තැන් පෙළක් එක් හිස්තැනක් කරයි; පේළි බිඳීම් අවට සහ දෙකෙළවරේ හිස්තැන් ඉවත් කරයි. පේළි බිඳීම් රැඳේ. | U+00A0 → හිස්තැන |

අනවශ්‍ය සම්බන්ධකයක් ස්වර ලකුණු නීතිවලින් ලකුණක් සඟවිය හැකි නිසා, සම්බන්ධක මුලින්ම සකසනු
ලැබේ. හොඳින් ලියූ පෙළට එක් වටයක් ප්‍රමාණවත්ය. වැරදි පෙළේදී එක් නීතියක් තවත් නීතියකට අවස්ථාව
ලබා දිය හැකි නිසා, පෙළ වෙනස් වීම නවතින තුරු (උපරිම වට හතරක්) නීති නැවත ක්‍රියාත්මක වේ. ඒ නිසා
`normalize()` දෙවරක් ධාවනය කළත් ප්‍රතිඵලය එකවර ධාවනය කළ විට ලැබෙන ප්‍රතිඵලයමය.

SLS 1134 අනුව සම්බන්ධකයේ ස්ථාන: යංශය (`ක්‍ය`), රකාරාංශය (`ක්‍ර`) සහ රේඵය (`ර්‍ක`) සඳහා හල්
කිරීමට පසුව, සහ බැඳි අකුරු (`ක‍්ව`) සඳහා හල් කිරීමට පෙර.

## පූර්ව සැකසුම් සහ විකල්ප {#presets-and-options}

`preset="standard"` (පෙරනිමිය) පෙන්වීමට සහ ගබඩා කිරීමට ආරක්ෂිතය. `preset="search"` සිංහල
අකුරු අසල ඇති සියලු සම්බන්ධකද ඉවත් කරයි; එවිට අක්ෂර වින්‍යාසයේ ප්‍රභේද එකිනෙක ගැළපේ:

```python
>>> sinling.normalize("ශ්\N{ZERO WIDTH JOINER}රී", preset="search") == "ශ්රී"
True

```

තනි නීති නමින් අක්‍රිය කළ හැකිය. `zwj` සඳහා `"canonical"`, `"strip"` හෝ `"keep"` ද,
`whitespace` සඳහා `"collapse"` හෝ `"keep"` ද දිය හැකිය:

```python
>>> sinling.normalize("  ගම  ", whitespace="keep")
'  ගම  '

```

## සාමාන්‍යකරණය නොකරන දේ {#what-normalization-does-not-do}

- පැරණි ෆොන්ට පෙළ හරවන්නේ නැත; ඒ සඳහා මුලින්ම [`from_legacy_font()`](legacy-fonts.md) භාවිත
  කරන්න.
- දීර්ඝ සහ හ්‍රස්ව ස්වර හෝ අක්ෂර වින්‍යාස ප්‍රභේද එක් කරන්නේ නැත; එය අර්ථය වෙනස් කරයි.
- දෙමළ අක්ෂරවලට දැනට අදාළ වන්නේ NFC සහ හිස්තැන් නීති පමණි.

## අක්ෂර {#aksharas}

`aksharas()` පෙළ සිංහල ලේඛනයේ අක්ෂරවලට (ලිඛිත අක්ෂර ඒකකවලට) බෙදයි. එය කිසිදු අකුරක් අහිමි
නොකරයි: ප්‍රතිඵලය එකතු කළ විට මුල් පෙළම ලැබේ.

```python
>>> print(" / ".join(sinling.aksharas("ශ්\N{ZERO WIDTH JOINER}රී ලංකාව")))
ශ්‍රී /   / ලං / කා / ව

```

ZWJ සම්බන්ධකයකින් (යංශය, රකාරාංශය, රේඵය හෝ බැඳි අකුරු) යා වූ ව්‍යඤ්ජනයක් ඊළඟ ව්‍යඤ්ජනය සමඟ එකම
අක්ෂරයක රැඳේ; හල් කිරීමක් පමණක් ඇති විට (`ස්ත`) අක්ෂරය එතැනින් අවසන් වේ. වෙනත් අක්ෂර
ක්‍රමවල අකුරු එකින් එක, ඒවාට පසුව එන සංයුක්ත ලකුණු සමඟ ලැබේ.
