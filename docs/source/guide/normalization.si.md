# පෙළ පිරිසිදු කිරීම

එකම සිංහල වචනය විවිධ ආකාරවලින් ගබඩා විය හැකිය. ස්වර ලකුණක් වැරදි අනුපිළිවෙළට ටයිප් කර, PDF
එකකින් පිටපත් කර, හෝ ඇතුළත නොපෙනෙන අකුරු සමඟ ඇලවූ ලෙස තිබිය හැකිය. තිරයේ ඒවා එක හා සමාන
ලෙස පෙනුණත්, පරිගණකය ඒවා වෙනස් වචන ලෙස සලකයි; ඒ නිසා සෙවීම සහ වචන ගණන් කිරීම වැරදේ.
`normalize()` පෙළ පිරිසිදු කරයි, එවිට එකම වචනය සෑම විටම එකම ආකාරයට ගබඩා වේ.

```python
>>> import sinling
>>> sinling.normalize("\N{ZERO WIDTH SPACE}\N{SINHALA VOWEL SIGN KOMBUVA}කා\N{NO-BREAK SPACE}අා")
'කො ආ'

```

`tokenize()`, `sentences()`, `stem()` සහ `from_legacy_font()` මුලින්ම ඔබේ පෙළ මේ ආකාරයට
පිරිසිදු කරයි. එය අවශ්‍ය නැත්නම් `normalize=False` දෙන්න.

## නිවැරදි කරන දේ {#what-it-fixes}

| විකල්පය | නිවැරදි කරන දේ | උදාහරණය |
| --- | --- | --- |
| `invisible` | නොපෙනෙන අකුරු ඉවත් කරයි: ශුන්‍ය-පළල හිස්තැන්, BOM, මෘදු යා-ඉරි සහ දිශා සලකුණු. | `ක` + ශුන්‍ය-පළල හිස්තැන + `ර` → `කර` |
| `zwj` | `ක්‍ය`, `ක්‍ර`, `ර්‍ක` සහ `ක‍්ව` හි භාවිත වන ශුන්‍ය-පළල සම්බන්ධකය (ZWJ) සිංහල යුනිකේත සම්මතය (SLS 1134) අපේක්ෂා කරන තැනට ගෙන යයි; අනවශ්‍ය සම්බන්ධක ඉවත් කරයි. emoji වල සම්බන්ධක නොවෙනස්ව තබයි. | `ක` + ZWJ + `්` + `ය` → `ක්‍ය` |
| `doubled_signs` | කොම්බු දෙක සඳහා ටයිප් කළ කොම්බු දෙකක් `ෛ` බවට හරවයි; `ෲ` සහ `ෳ` සඳහාද එසේමය. | `ම` + `ෙ` + `ෙ` → `මෛ` |
| `reorder` | පැරණි ටයිප් යන්ත්‍රයක මෙන් අකුරට පෙර ටයිප් කළ කොම්බුවක් අකුරට පසුවට ගෙන යයි. | `ෙ` + `ග` → `ගෙ` |
| `vowel_letters` | ස්වර අකුරක් සහ ලකුණක් එක් ස්වර අකුරක් බවට හරවයි. | `අ` + `ා` → `ආ` |
| `nfc` | කොටස් දෙකකට ටයිප් කළ ස්වර ලකුණු එක් කරයි. | `ක` + `ෙ` + `ා` → `කො` |
| `whitespace` | හිස්තැන් සහ ටැබ් පෙළක් එක් හිස්තැනක් කර, සෑම පේළියකම කෙළවර කපා හරියි. පේළි බිඳීම් රැඳේ. | නොබිඳෙන හිස්තැන → හිස්තැන |

දැනටමත් පිරිසිදු පෙළක් මත `normalize()` ධාවනය කළත් එය වෙනස් නොවේ.

## විකල්ප {#options}

පෙරනිමිය පෙළ පෙන්වීමට සහ ගබඩා කිරීමට ආරක්ෂිතය. සෙවීම සඳහා `preset="search"` භාවිත කරන්න;
එය සම්බන්ධකද ඉවත් කරන නිසා `ශ්‍රී` සහ `ශ්රී` ගැළපේ:

```python
>>> sinling.normalize("ශ්\N{ZERO WIDTH JOINER}රී", preset="search") == "ශ්රී"
True

```

ඕනෑම නිවැරදි කිරීමක් එහි විකල්ප නාමයෙන් අක්‍රිය කරන්න. `zwj` සඳහා `"strip"` (සියලු සම්බන්ධක
ඉවත් කිරීම) හෝ `"keep"` ද, `whitespace` සඳහා `"keep"` ද දිය හැකිය:

```python
>>> sinling.normalize("  ගම  ", whitespace="keep")
'  ගම  '

```

## නොකරන දේ {#what-it-doesnt-do}

- පැරණි ෆොන්ටවලින් ටයිප් කළ පෙළ හරවන්නේ නැත; ඒ සඳහා [`from_legacy_font()`](legacy-fonts.md) භාවිත කරන්න.
- අක්ෂර වින්‍යාසය හෝ දීර්ඝ, හ්‍රස්ව ස්වර වෙනස් කරන්නේ නැත; එයින් අර්ථය වෙනස් විය හැකිය.
- දෙමළ පෙළේ කරන්නේ ස්වර ලකුණු එක් කිරීම සහ හිස්තැන් පිළිවෙළ කිරීම පමණි.

## අක්ෂර {#aksharas}

`aksharas()` පෙළ සිංහල ලේඛනයේ අක්ෂරවලට බෙදයි. කිසිවක් අහිමි නොවේ: කොටස් එකතු කළ විට මුල්
පෙළම ලැබේ.

```python
>>> print(" / ".join(sinling.aksharas("ශ්\N{ZERO WIDTH JOINER}රී ලංකාව")))
ශ්‍රී /   / ලං / කා / ව

```

`ශ්‍රී` හෝ `ක්‍ය` හි මෙන් ZWJ එකකින් යා කළ අකුරු එකම අක්ෂරයක රැඳේ. `ස්ත` හි මෙන් පෙනෙන හල්
කිරීමක් සහිත අකුරක් තනිවම අක්ෂරයකි. වෙනත් අක්ෂර ක්‍රමවල අකුරු එකින් එක ලැබේ.
