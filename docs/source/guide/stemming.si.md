# ප්‍රකෘතිය සෙවීම

`stem()` සෑම වචන ටෝකනයක්ම එහි ප්‍රකෘතියට (stem) අඩු කරයි. විරාම ලකුණු වැනි අනෙක් ටෝකන
නොවෙනස්ව පවතී.

```python
sinling.stem("පොත්වලින් කියවන්න.")                 # ['පොත', 'කියව', '.']
sinling.stem("පිහිටවීමට", backend="dictionary")    # ['පිහිටවීම']
```

## Backends {#backends}

| Backend | ක්‍රියා කරන ආකාරය | බාගැනීම් |
| --- | --- | --- |
| `suffix` (පෙරනිමිය) | හඳුනන දිගම ප්‍රත්‍යය ඉවත් කරයි. තනිවම ප්‍රත්‍යයක් වන වචනයක් එලෙසම තබයි. | ප්‍රත්‍යය ලැයිස්තුව (6 KB) |
| `dictionary` | මුලින්ම වචන 27,197 ක ප්‍රකෘති ශබ්දකෝෂයේ සොයයි; ඉන්පසු ප්‍රත්‍යය ඉවත් කරයි. | ප්‍රත්‍යය ලැයිස්තුව සහ ප්‍රකෘති ශබ්දකෝෂය (1.3 MB) |

ශබ්දකෝෂයේ ප්‍රකෘතිය වෙනත් අක්ෂර වින්‍යාසයක් නම් (ඉන්දීය → ඉන්දියාව), ප්‍රකෘතිය හිස් ප්‍රත්‍යයක්
සමඟ ලැබේ. ශබ්දකෝෂ සෙවීම ශුන්‍ය-පළල සම්බන්ධක නොසලකයි; ඒ නිසා `ප්‍රශ්නයට` ශබ්දකෝෂයේ ඇති
`ප්රශ්නයට` සමඟ ගැළපේ, සහ සම්බන්ධකය ප්‍රකෘතිය තුළ රැඳේ.

නල මාර්ගයක් තුළ සෑම ටෝකනයකටම `attrs["stem"]` සහ `attrs["suffix"]` ලැබේ:

```python
nlp = sinling.pipeline(["normalize", "tokenize", "stem"])
doc = nlp("පොත්වලින් 500ක්")
[(t.attrs["stem"], t.attrs["suffix"]) for t in doc.tokens]
# [('පොත', '්වලින්'), ('500', 'ක්')]
```

ප්‍රත්‍යයක් ස්වර ලකුණකින් හෝ හල් කිරීමකින් ආරම්භ විය හැකි නිසා, ප්‍රකෘතියක් අක්ෂරයක් මැදින්
අවසන් විය හැකිය (`පිහිටවීමට` → `පිහිටව` + `ීමට`). මුල් ඇල්ගොරිතමය ක්‍රියා කරන්නේ එලෙසය.
