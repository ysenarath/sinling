# වචනවල ප්‍රකෘතිය සෙවීම

`stem()` සෑම වචනයකම ප්‍රකෘතිය සොයයි: `වලින්` හෝ `ට` වැනි අගින් එන කොටස් ඉවත් කළ පසු ඉතිරි වන
කොටස. විරාම ලකුණු සහ වචන නොවන අනෙක් දේ එලෙසම ලැබේ.

```python
sinling.stem("පොත්වලින් කියවන්න.")                 # ['පොත', 'කියව', '.']
sinling.stem("පිහිටවීමට", backend="dictionary")    # ['පිහිටවීම']
```

## ප්‍රකෘතිය සොයන ක්‍රම දෙක {#two-ways-to-find-stems}

| `backend=` | ක්‍රියා කරන ආකාරය | පළමු භාවිතයේදී බාගන්නා දේ |
| --- | --- | --- |
| `suffix` (පෙරනිමිය) | තමා දන්නා දිගම ප්‍රත්‍යය ඉවත් කරයි. | ප්‍රත්‍යය ලැයිස්තුවක් (6 KB) |
| `dictionary` | මුලින්ම වචන 27,197 ක ශබ්දකෝෂයේ වචනය සොයා, පසුව ප්‍රත්‍යය ඉවත් කරයි. | ප්‍රත්‍යය ලැයිස්තුව සහ ශබ්දකෝෂය (1.3 MB) |

සමහර විට ශබ්දකෝෂය ප්‍රකෘතිය ලෙස වෙනත් අක්ෂර වින්‍යාසයක් දෙයි, උදාහරණයක් ලෙස ඉන්දීය → ඉන්දියාව.
`ප්‍රශ්නයට` වැනි යා කළ අකුරක් සහිත වචනද ශබ්දකෝෂයේ සොයා ගැනේ.

නල මාර්ගයක් තුළ, සෑම ටෝකනයකටම එහි ප්‍රකෘතිය සහ ඉවත් කළ ප්‍රත්‍යය ලැබේ:

```python
nlp = sinling.pipeline(["normalize", "tokenize", "stem"])
doc = nlp("පොත්වලින් 500ක්")
[(t.attrs["stem"], t.attrs["suffix"]) for t in doc.tokens]
# [('පොත', '්වලින්'), ('500', 'ක්')]
```

ප්‍රත්‍යයක් ස්වර ලකුණකින් හෝ හල් කිරීමකින් ආරම්භ විය හැකි නිසා, ප්‍රකෘතියක් අක්ෂරයක් මැදින්
අවසන් විය හැකිය; උදාහරණයක් ලෙස `පිහිටවීමට` → `පිහිටව` + `ීමට`. ප්‍රකෘතිය සෙවීම පමණක් සෙවීම
බොහෝ සෙයින් වැඩිදියුණු නොකරයි; අපගේ පරීක්ෂණවලදී එයින් සුළු වෙනසක් පමණක් සිදු විය.
