# පැරණි ෆොන්ට

යුනිකේත පොදු වීමට පෙර සිංහල ටයිප් කළේ ලතින් අකුරු මත සිංහල අකුරු අඳින ෆොන්ට (fonts)
භාවිතයෙනි. එවැනි ෆොන්ට එකක් භාවිත කරන PDF හෝ Word ගොනුවකින් ලබාගත් පෙළ තේරුමක් නැති අකුරු
ලෙස පෙනේ: `වාතය` වෙනුවට `jd;h`. බොහෝ රජයේ ලේඛන සහ පාසල් පෙළපොත් තවමත් ඒවා භාවිත කරයි.

`from_legacy_font()` එම පෙළ යුනිකේත බවට හරවා, පසුව සාමාන්‍යකරණය කරයි:

```python
>>> import sinling
>>> sinling.from_legacy_font('jd;h" c,h" wdydr')
'වාතය, ජලය, ආහාර'

>>> sinling.from_legacy_font("fomd\xbe;f\xefka;=j")
'දෙපාර්තමේන්තුව'

```

## සහාය දක්වන ෆොන්ට {#supported-fonts}

| Backend | ෆොන්ට |
| --- | --- |
| `fm` (පෙරනිමිය) | FM පවුල: FMAbhaya, FMMalithi, FMEmanee, FMAbabld සහ විජේසේකර පිරිසැලසුම බෙදාගන්නා අනෙකුත් ෆොන්ට. |

DL ෆොන්ට සහ Bamini වැනි දෙමළ පැරණි ෆොන්ට සැලසුම් කර ඇත.

`fm` වගු ගොඩනැගුවේ අධ්‍යාපන ප්‍රකාශන දෙපාර්තමේන්තුවේ පෙළපොත් ඇසුරෙනි. ඉන් පොත් 31 කින්
ලබාගත් අකුරු මිලියන 2.8 ක පෙළක් මත, ප්‍රතිඵලය එය මුලින් ලියූ පරිවර්තකයේ ප්‍රතිඵලයට හරියටම
සමාන විය.

## පැරණි ෆොන්ට පෙළ පමණක් හරවන්න {#only-convert-legacy-font-text}

පරිවර්තකය ලතින් අකුරු සහ විරාම ලකුණු වෙනස් කරන නිසා, සාමාන්‍ය ඉංග්‍රීසි හෝ යුනිකේත ෆොන්ට
පෙළ විකෘති වේ. PDF එකක, ෆොන්ට එක පැරණි ෆොන්ට එකක් වන කොටස් පමණක් හරවන්න. `is_fm_font()`
FM ෆොන්ට නමෙන් හඳුනා ගනී; උප-කට්ටල උපසර්ග සහ නම "FM" වලින් ආරම්භ නොවන FM ෆොන්ට තුනද
ඇතුළුව:

```python
>>> from sinling.legacy_fonts import is_fm_font
>>> is_fm_font("ABCDEF+FMAbhaya"), is_fm_font("SARAWIPULA"), is_fm_font("Iskoola Pota")
(True, True, False)

```

යුනිකේත සිංහල නොවෙනස්ව ගමන් කරයි; ඒ නිසා දැනටමත් යුනිකේත වන කොටසක් ආරක්ෂිතය.

## හිඩැස් සහ ස්ථාන {#gaps-and-offsets}

පරිවර්තකයට සිතියමක් නැති අකුරු එලෙසම තබා `doc.meta["legacy_font_unmapped"]` හි ගණන් කෙරේ;
එය වගුවල හිඩැස් සොයා ගැනීමට උපකාරී වේ:

```python
>>> doc = sinling.pipeline(["legacy_font"])("jd;h\N{EURO SIGN}")
>>> doc.text, doc.meta["legacy_font_unmapped"]
('වාතය€', {'€': 1})

```

ෆොන්ට එක ව්‍යඤ්ජනයට පෙර ගබඩා කරන ස්වර ලකුණු ඇතුළුව, සෑම හැරවූ අකුරක්ම ලබාගත් පෙළට ආපසු
සිතියම්ගත වේ:

```python
>>> doc = sinling.pipeline(["legacy_font"])("frda.")
>>> doc.text, doc.raw[slice(*doc.to_raw(0, 2))]
('රෝග', 'frda')

```
