# Sinling

Sinling යනු Python තුළ සිංහල (සිංහල) පෙළ සමඟ වැඩ කිරීමට ඇති මෙවලම් කට්ටලයකි. එය පෙළ
පිරිසිදු කරයි, වචන සහ වාක්‍යවලට බෙදයි, වචනවල ප්‍රකෘතිය සොයයි, සහ පැරණි සිංහල ෆොන්ටවලින් ටයිප්
කළ පෙළ නිවැරදි යුනිකේත (Unicode) බවට හරවයි.

!!! warning "Sinling 0.4 තවමත් පෙර-නිකුතුවකි"
    0.4 යනු 0.3 ට වඩා වෙනස් ලෙස ක්‍රියා කරන නව අනුවාදයකි. සාමාන්‍ය `pip install sinling` තවමත්
    0.3 ස්ථාපනය කරයි. ඔබේ කේතය 0.3 සඳහා ලියා ඇත්නම්, `sinling<0.4` සමඟ එය දිගටම භාවිත කරන්න,
    නැතහොත් එය යාවත්කාලීන කිරීමට [මාරු වීමේ මාර්ගෝපදේශය](migration.md) බලන්න.

## ස්ථාපනය {#installation}

```
pip install --pre sinling
```

Python 3.11 හෝ ඊට නවතම අනුවාදයක් අවශ්‍යයි. ඒ සමඟ වෙනත් කිසිවක් ස්ථාපනය නොවේ.

## ඉක්මන් ආරම්භය {#quick-start}

සෑම කාර්යයක්ම එක් ශ්‍රිතයකි. එයට පෙළ දුන් විට, පෙළක් හෝ ලැයිස්තුවක් ලැබේ:

```python
>>> import sinling

>>> sinling.normalize("\N{SINHALA VOWEL SIGN KOMBUVA}ගදර\N{NO-BREAK SPACE}යනවා")
'ගෙදර යනවා'

>>> sinling.tokenize("පෙ.ව. 10ට රු.500ක් ගෙවන්න.")
['පෙ.ව.', '10ට', 'රු.', '500ක්', 'ගෙවන්න', '.']

>>> sinling.sentences("මම ගෙදර යනවා. ඔයා එනවද?")
['මම ගෙදර යනවා.', 'ඔයා එනවද?']

```

දේවල් කිහිපයක් එකවර කිරීමට නල මාර්ගයක් (pipeline) භාවිත කරන්න. එය වචන සහ වාක්‍ය රඳවා ගන්නා,
ඒවා ඔබේ මුල් පෙළේ තිබුණු තැන මතක තබා ගන්නා `Doc` එකක් ලබා දෙයි:

```python
>>> doc = sinling.pipeline()("මම ගෙදර යනවා. ඔයා එනවද?")
>>> [token.text for token in doc.tokens]
['මම', 'ගෙදර', 'යනවා', '.', 'ඔයා', 'එනවද', '?']
>>> len(doc.sents)
2

```
